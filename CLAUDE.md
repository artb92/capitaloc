# Capitaloc

Daily geography game: 10 countries per day, the player pins each capital on a map within 5 s;
score depends on distance. Static SPA on Cloudflare Pages; the only backend is the daily
leaderboard on Supabase (`supabase/`).

## Stack
Vite 8 · React 19 · TypeScript (strict) · MapLibre GL via `react-map-gl/maplibre` · Tailwind v4 ·
Zustand (game state) · Vitest + Testing Library · Biome (lint + format) · pnpm.

## Commands
- `pnpm dev`: dev server at http://localhost:5173 (strict port)
- `pnpm check`: lint + typecheck + tests. **Run before every commit.**
- `pnpm fix`: auto-format and fix lint
- `pnpm test -- <pattern>`: run a subset of tests
- `pnpm build` / `pnpm preview` (http://localhost:4173)
- `pnpm build:function`: bundle `src/features/leaderboard/handler.ts` into the `submit-score` Edge Function
  (`.github/workflows/supabase.yml` runs it, pushes migrations and deploys on main)
- `pnpm data:countries`: regenerate `src/data/countries.json` (downloads Natural Earth)
- `pnpm data:physical`: regenerate `src/data/physical.json` (sea, lakes, ice, rivers, deep ocean)
- `pnpm data:relief`: regenerate `public/relief/` shaded-relief tiles z0–6 (downloads ~4k terrain tiles)
- `pnpm data:satellite`: regenerate `public/satellite/` tiles z0–6 (NASA Blue Marble, ~120 MB download)
- Dev builds show "Map: …" (switch satellite/relief base map) and "Reset (dev)" (replay today) in the header

## Layout
- `src/app/`: app shell, screens
- `src/features/<feature>/`: feature code, colocated tests (`*.test.ts[x]`)
- `src/lib/`: pure, framework-free helpers (geo math, seeded RNG, daily pick, scoring)
- `src/features/game/`: game state machine (`logic.ts`, pure), Zustand store, history/stats
- `src/features/leaderboard/`: score verification (`verify.ts`, shared with the server), Edge Function
  handler, browser client. The board shows only when `VITE_SUPABASE_URL` and `VITE_SUPABASE_KEY` are set
- `supabase/`: migrations and the Edge Function entry point
- `src/features/i18n/`: EN/FR messages; `Messages` type forces both to stay in sync
- `src/data/*.json`: generated by `scripts/build-*.mjs`, never edit by hand (Biome skips them)
- `public/`: brand assets (`favicon.svg` is the logo mark, `og.png` share image, `apple-touch-icon.png`)
- Import from `src` with the `@/` alias

## Conventions
- Keep game logic pure and in `src/lib` or `features/*/logic.ts`; components stay thin.
- Unit-test every pure function; no snapshot tests. Tests run in node by default; component
  tests add `// @vitest-environment jsdom` on line 1.
- Every user-facing string goes through `useI18n()` in both languages.
- Map style is label-free (`features/map/mapStyle.ts`): never add a tile source with place
  names, roads or cities, it would reveal answers. Everything is self-hosted. Two base maps
  (`features/map/basemap.ts`, default satellite): satellite tiles in `public/satellite/`, or relief
  tiles in `public/relief/` with sea/lakes/rivers vectors drawn over them. The country highlight
  sits under the shared `highlight-anchor` layer, which every style must keep.
- Named exports only; no default exports except where a tool requires one.
- Conventional commits (`feat:`, `fix:`, `chore:` …).

## Gotchas
- `maplibre-gl` v6 must stay in `optimizeDeps.exclude` (vite.config.ts) or its worker fails to load.
- Capital photos come from Wikimedia at runtime; this sandbox cannot reach it, so browser tests
  must stub `wikidata.org` and `commons.wikimedia.org` routes. Node scripts that download need
  `NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt` here.
- Natural Earth layers in one mapshaper dataset share arcs, so `-simplify` hits all of them:
  `build-physical.mjs` simplifies each layer on its own before combining.
- `world-atlas` rings are spherical; `unwrapRing` in `features/map/countries.ts` fixes antimeridian stripes.

## Design
Colours and animations are Tailwind v4 theme tokens in `src/index.css` (ink scale, one `accent`,
score tiers). Use them, not raw hex. Animations use `motion-safe:` so reduced motion is respected.

## Token hygiene (for Claude)
- Don't read `pnpm-lock.yaml`, `node_modules/`, `dist/` or geo data JSON; they are denied in
  `.claude/settings.json`. Inspect data with a short `node -e` script that prints a summary.
- Prefer `pnpm check` output tails (`| tail -30`) over full logs.
- Record product decisions in `docs/decisions.md`, one line each, instead of re-deriving them.
