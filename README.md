# Capitaloc Game

Capitaloc is an Android game where players test their geographical knowledge by pinning the location of a country's capital based solely on an outline map of the country. The game challenges players to improve their understanding of world geography in a fun and interactive way.

## Features

- **Main Activity**: The entry point of the application, providing the main user interface.
- **Game Activity**: Handles the game logic and user interactions during gameplay.
- **Country and Capital Models**: Represents countries and their capitals with relevant properties.
- **Game Management**: Manages the game state, including starting and ending the game.
- **Score Calculation**: Calculates the player's score based on their performance.
- **Country Data Handling**: Loads and parses country data from a JSON file.
- **User Interface**: Custom layouts for the main and game activities.
- **Resource Management**: String, color, and style resources for a consistent look and feel.
- **Unit Testing**: Includes sample unit tests to ensure code quality.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Capitaloc.git
   ```
2. Open the project in Android Studio.
3. Build and run the application on an Android device or emulator.
